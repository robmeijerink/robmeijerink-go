Data Aggregation · 2026

Data Aggregation Engine

A platform pulled data from a dozen internal and third-party sources and merged it per request, which got slower with every new customer. We rebuilt the aggregation layer in Rust: concurrent fetching, streaming merges, and predictable response times with bounded memory use.

Rust · Tokio · Axum · PostgreSQL · Redis

aggregate.rsRust
async fn aggregate(req: Query, sources: &[Source]) -> Result<Report> {
    // Fetch every source concurrently
    let parts = try_join_all(sources.iter().map(|s| s.fetch(&req))).await?;
 
    // Merge as a stream, bounded memory
    let report = stream::iter(parts)
        .fold(Report::default(), |acc, p| async move { acc.merge(p) })
        .await;
 
    Ok(report)
}

Shared Core · 2026

One Calculation Engine, Everywhere

Pricing and planning rules that existed in three slightly different versions. Extracted into one Rust library, exposed to PHP through FFI and to the browser through WebAssembly, so every surface now produces identical results.

Rust · WebAssembly · FFI · Laravel · TypeScript

lib.rsRust
pub fn calculate(input: &Input) -> Quote {
    Quote::from_rules(input, &RULES)
}
 
// Browser
#[wasm_bindgen]
pub fn calculate_js(json: &str) -> String {
    to_json(&calculate(&from_json(json)))
}
 
// PHP, via FFI
#[no_mangle]
pub extern "C" fn calculate_c(ptr: *const c_char) -> *mut c_char {
    to_c(&calculate(&from_c(ptr)))
}
